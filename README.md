### ROI Selector — Planogram Shelf Coordinate Tool

**Workflow**

2. Select shelf regions
3. Enter a name/code for each region
4. Store the selected coordinates
5. Export the results to Excel

This project helped me understand image-coordinate handling, data processing, and building a small practical Python application.
